## Bunnies

Bunnies is a RabbitMQ management GUI.

## Installation

Use a package manager npm in order to install all dependencies

```bash
npm install
```

## Usage

Just run `start` script.

```bash
npm run start
```

## Packaging

To generate the project package based on the OS you're running on, just run:

```bash
npm run package
```
